# CMJ 個票の見方ガイド

Counter Movement Jump — 個票インタラクティブ解説アプリ

大阪体育大学スポーツ科学センター 測定評価・S&C部門

---

## 概要

CMJ（カウンタームーブメントジャンプ）測定後に配布される個票の見方を、インタラクティブに解説する Web アプリです。個票の各項目をクリックすると、その項目の意味・計算方法・見方のポイントが表示されます。

## 機能

- **個票プレビュー** — 実際の個票レイアウトを再現。クリックで各項目の解説を表示
- **項目別解説** — 跳躍高・滞空時間・部内順位・評価（グレード）・偏差値・散布図
- **2ページ目解説** — CMJの定義・跳躍力が示す能力・トレーニングポイント・活用法

## 解説項目

| 項目 | 内容 |
| --- | --- |
| 跳躍高 [cm] | 滞空時間からの算出式・目安値 |
| 滞空時間 [秒] | 赤外線センサーの計測原理 |
| 部内順位 | チーム内ランキングの見方 |
| 評価（1〜5） | 偏差値ベースの5段階グレード表 |
| 偏差値 | 計算式・人数による信頼性 |
| 散布図 | 軸の意味・外れ値の見方 |

## 動作環境

- モダンブラウザ（Chrome / Edge / Firefox / Safari）
- サーバー不要。HTML ファイルをダブルクリックして直接開いて使用可能

## 使い方

1. `index.html` をブラウザで開く
2. 左の個票プレビューの各項目をクリック
3. 右パネルに解説が表示される
4. 下部ボタンで 2 ページ目（CMJ解説）を展開
